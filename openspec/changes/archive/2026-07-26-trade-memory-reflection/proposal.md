## Why

#5 的 Agent 能决策,但「不长记性」。本 change 补上记忆-反思回路(design D5):记录每笔交易(策略/盈亏/开平仓价量/杠杆/理由),并实现三层反哺——(a) **RAG**:检索相似历史交易+反思注入决策;(b) **参数自调**:反思产出可执行的风控/策略参数建议;(c) **规则库**:反思提炼经验规则注入系统提示。让 Agent「越交易越聪明」。

## What Changes

- 新增**交易日志**:持久化每笔交易(开/平仓价、名义/保证金、杠杆、PnL、策略、理由、反思、情境特征),JSONL 存储、可加载。
- 新增**记忆检索(a)**:按情境特征(如相对支撑距离、MACD 方向、KDJ 区间、方向)对历史**已平仓**交易做相似度检索,返回 Top-K。
- 新增**反思引擎**:
  - 生成反思文本(启发式基线 + 可选注入 LLM)。
  - **参数自调(b)**:据近期表现产出风控/策略参数调整建议(如胜率过低→提高 `min_strength`)。
  - **规则库(c)**:从模式中提炼经验规则文本。
- 新增**记忆整合**:把检索到的相似交易 + 经验规则注入 Agent 决策上下文(供 #5 的 provider 使用)。
- 纯逻辑 + 轻量本地存储(无向量库/嵌入模型依赖),确定性、可离线测试。

## Capabilities

### New Capabilities
- `trade-journal`: 交易记录持久化与加载。
- `memory-retrieval`: 相似历史交易的 RAG 式检索(a)。
- `reflection-engine`: 反思生成 + 参数自调建议(b) + 规则提炼(c)。
- `memory-integration`: 将记忆与规则注入决策上下文。

## Impact

- **依赖**:仅标准库 + 现有 pandas;**不引入向量库/嵌入模型**(相似度用情境特征数值 + 关键词重叠)。
- **代码**:`backend/src/market_data/memory.py`;CLI 增加 `memory`(展示日志统计/规则/参数建议)。
- **对齐路线图**:实现 #6;DL(#7)、自动化(#8)、前端(#9)不在本 change。
- **安全**:参数自调仅产出**建议**,是否应用由上层决定(防过拟合);不改动已归档模块的既有行为。
